🏬 HIPMI PT IBI Kesatuan Catalog (HIPMORA)

Selamat datang di repositori resmi HIPMI PT IBI Kesatuan Business Catalog & Web Directory (hipmora.my.id).

Platform ini dirancang khusus untuk mempublikasikan, mendata, dan mempromosikan katalog bisnis serta profil wirausaha muda anggota HIPMI PT (Himpunan Pengusaha Muda Indonesia Perguruan Tinggi) IBI Kesatuan Bogor.

📌 Tentang Proyek

HIPMORA bertujuan untuk membangun ekosistem kewirausahaan digital yang terintegrasi bagi mahasiswa dan alumni IBI Kesatuan. Melalui platform ini, publik dan sesama anggota dapat dengan mudah menemukan berbagai produk, layanan, serta bidang usaha yang dijalankan oleh para pengusaha muda.

✨ Fitur Utama

🗂️ Katalog Bisnis Terstruktur: Menampilkan daftar usaha anggota lengkap dengan deskripsi, kategori, dan kontak resmi.

🔍 Pencarian & Filter: Kemudahan mencari unit bisnis berdasarkan kategori produk/jasa.

🌐 Profil Anggota & Jejaring: Memfasilitasi kolaborasi antar-pengusaha muda (B2B & B2C).

📱 Desain Responsiif: Tampilan yang nyaman diakses melalui perangkat seluler (mobile), tablet, maupun desktop.

📢 Informasi & Event: Media publikasi kegiatan, seminar, dan business matching HIPMI PT IBI Kesatuan.

🚀 Panduan Memulai (Local Setup)

Untuk menjalankan proyek ini secara lokal di komputer Anda:

1. Prasyarat

Git terinstal di komputer Anda.

Web browser modern (Chrome, Firefox, Edge, Safari).

Local server software (seperti XAMPP, Live Server VS Code, atau Node.js jika menggunakan framework).

2. Kloning Repositori

git clone https://github.com/denny-wijaya-11/HIPMI-KESATUAN-CATALOG.git
cd HIPMI-KESATUAN-CATALOG


3. Jalankan Project

Jika proyek ini berbasis file statis (HTML/CSS/JS):

Buka file index.html langsung di browser Anda, atau

Gunakan ekstensi Live Server di VS Code untuk pengalaman pengembangan yang lebih optimal.
